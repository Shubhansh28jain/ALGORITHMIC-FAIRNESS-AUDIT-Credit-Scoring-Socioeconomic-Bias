# ALGORITHMIC-FAIRNESS-AUDIT-Credit-Scoring-Socioeconomic-Bias
It merges with U.S. Census demographic data by zip code.
Trains XGBoost credit risk model (race excluded as input).
Audits model outputs for disparate impact across racial groups.
Computes fairness metrics: Demographic Parity, Equalized Odds, Disparate Impact Ratio.
Generates full dashboard of results.
